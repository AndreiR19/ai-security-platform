# AI Security Operations Platform

O platforma de operatiuni de securitate bazata pe inteligenta artificiala, conceputa pentru detectia, analiza si raspunsul la incidente de securitate cibernetica. Proiectul foloseste Python si modele AI pentru automatizarea fluxurilor SOC (Security Operations Center).

## Cerinte

- Python 3.12+
- Dependinte: pydantic, pytest, 
ruff

## Pornire

Bash
# Creeaza si activeaza mediul virtual
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Instaleaza dependintele
pip install -r requirements.txt

# Ruleaza testele
pytest -v
